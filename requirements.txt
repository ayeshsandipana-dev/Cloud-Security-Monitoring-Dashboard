# ☁️ Cloud Security Monitoring Dashboard

An interactive cybersecurity monitoring application built using Python, Streamlit, Plotly, and SQLite.

This project demonstrates cloud security event monitoring, failed login detection, suspicious activity analysis, and security reporting.

## 🛡️ Project Overview

The Cloud Security Monitoring Dashboard is an educational security operations project designed to analyze simulated cloud security logs.

It detects repeated failed login attempts and presents security insights through an interactive dashboard.

## 🚀 Key Features

- Cloud Security Log Analysis
- Failed Login Detection
- Repeated Login Failure Alerts
- Security Event Visualization
- Suspicious IP Monitoring
- SQLite Database Integration
- Interactive Streamlit Dashboard
- CSV Security Report Export
- Security Event Statistics

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://www.credly.com/badges/f335269d-6b52-4374-bd2d-551532955f56/public_url
```

### 2. Open Project Directory

```bash
cd Cloud-Security-Monitoring-Dashboard
```

### 3. Create Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate Environment (Windows PowerShell)

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

## ▶️ How to Run

Generate simulated cloud logs:

```bash
python generate_logs.py
```

Run the security analyzer:

```bash
python log_analyzer.py
```

Save security alerts to SQLite:

```bash
python database.py
```

Launch the dashboard:

```bash
python -m streamlit run app.py
```

Open the local Streamlit URL displayed in the terminal.

## 🔍 Detection Logic

The system identifies repeated failed login attempts originating from the same source IP address.

An alert is generated when at least five failed login events occur within a ten-minute window.

This is a demonstration rule and does not independently prove malicious activity.

## 🧪 Testing

The project includes a test script that adds simulated failed login events to the dataset.

```bash
python test_alerts.py
python log_analyzer.py
```

Note: Repeatedly running the test script may duplicate test events.
